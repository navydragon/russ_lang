# Design

## Context

В проекте есть механизмы чтения с распознаванием и паузами, устного пересказа и письменных изложений. Источники собраны в `tasks/lesson7/NEW_ASSIGNMENTS_SOURCE.md`, текст вечера хранится в `faculty_text.json`. Каталог готовых заданий отдельно от списка запланированных карточек участвует в подготовке тестовых данных и синхронизации курса.

## Goals / Non-Goals

**Goals:** получить шесть независимых результатов и доступные ссылки для каждого задания; переиспользовать существующие механизмы.

**Non-Goals:** новые задания уроков 5–6 и расширение акустической оценки произношения.

## Decisions

- Выделить последовательные свободные коды `AI_7_7`–`AI_7_12` в порядке из предложения и сохранить коды существующих заданий. По завершении перенести соответствующие карточки из списка запланированных в каталог готовых, не оставляя дублей.
- Чтение подключить к существующей серверной проверке полноты, длительности и пауз с лимитом 120 секунд, порогами и шкалой как у существующих страниц. Числительные Гагарина представить проверяемыми словесными вариантами, сохранив читаемое отображение дат; проверить нормализацию и произнесённые варианты. В качестве источника использовать только 27.3; исправить «Юрия Гагарина» и повтор «марта» после года.
- Для сказки использовать текст из `NEW_ASSIGNMENTS_SOURCE.md`, сверив повтор диалога с исходным слайдом. Для устного пересказа использовать существующий ASR и отдельную рубрику. Изложение «Вечер на факультете» оценивать по содержанию исходного текста, грамотности и связности; по аналогии с существующими письменными заданиями проходной балл 60 из 100.
- Для видовых пар подготовить перечень лемм, контекстных вариантов и слов без обычной пары; проверять ответ содержательно с обратной связью, не требуя единственной формулировки. Это избегает ложных ошибок при допустимых вариантах.
- Определить источник аудиообразца по доступным материалам. Если запись отсутствует, использовать подход существующих заданий без образца и не обещать прослушивание; если запись создаётся, обеспечить её воспроизведение и соответствие тексту.
- Обновить реестр каталога, запуск тестовых данных, карточки для авторов и локальную страницу, перечень и даты изменений. Проверить влияние каталога на синхронизацию курса до применения синхронизации; автоматически её не запускать.

## Risks / Trade-offs

- [Текст ВДНХ и двухминутный лимит] → проверить объём и поведение ограничения, не изменяя авторский лимит.
- [Числительные и распознавание речи] → покрыть датировки и время тестами для нескольких корректных вариантов.
- [Качество видовых пар] → исключить искусственные пары и явно описать допускаемые варианты и случаи отсутствия пары.
- [Зависимость от внешних сервисов] → тестировать отказы отдельно, не объявлять реальные запросы проверенными без фактического прогона.

## Migration Plan

Добавить новые коды и ресурсы, подготовить локальные тестовые записи существующей командой, проверить ссылки и сохранение. Старые коды, попытки и подтверждения сохранить; откат кода и ресурсов не должен удалять сохранённые результаты.
