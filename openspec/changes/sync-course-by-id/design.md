# Design

## Context

Команда работает в транзакции, обнаруживает конфликты кодов глобально и без параметра ищет курс по имени.

## Goals / Non-Goals

Выбирать существующую запись по первичному ключу. Создание курса с заданным первичным ключом не входит в изменение.

## Decisions

Параметр `--course-id` выбирает существующий курс и сохраняет его название и привязку WebSoft. Без параметра сохраняется прежнее поведение. Конфликты кодов в других курсах прерывают операцию. В PostgreSQL сохраняются блокировки.

## Risks / Trade-offs

Задания с одинаковым кодом в других курсах блокируют синхронизацию: это защищает сохранение результатов от неоднозначности.
