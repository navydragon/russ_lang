# Proposal

## Why

Существующий курс нельзя выбрать по внутреннему ID для синхронизации уроков и заданий.

## What Changes

- Добавить выбор существующего курса по внутреннему ID при сохранении режима плана и идемпотентности.
- Проверить полноту каталога AI и сохранить защиту от конфликтов кодов.

## Capabilities

### New Capabilities

- `course-sync-by-id`: безопасная синхронизация указанного курса.

### Modified Capabilities

Нет.

## Impact

Команда Django, план синхронизации, тесты и документация.
