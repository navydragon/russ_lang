## ADDED Requirements

### Requirement: Синхронизация выбранного курса

Команда SHALL принимать внутренний ID существующего курса и добавлять недостающие уроки и задания из текущего каталога.

#### Scenario: Повторное применение

- **WHEN** команда дважды применена к одному курсу
- **THEN** второй запуск не создаёт дубли и сохраняет существующие результаты и привязку WebSoft

#### Scenario: Курс отсутствует

- **WHEN** передан ID несуществующего курса
- **THEN** команда завершается ошибкой без изменений

#### Scenario: Конфликт кода

- **WHEN** нужный код занят заданием другого курса или урока
- **THEN** команда сообщает об ошибке и отменяет транзакцию

#### Scenario: Предварительный просмотр

- **WHEN** команда запущена без `--apply`
- **THEN** она выводит план и не изменяет данные

#### Scenario: Совместимость

- **WHEN** внутренний ID не указан
- **THEN** используется существующее поведение выбора курса по имени
