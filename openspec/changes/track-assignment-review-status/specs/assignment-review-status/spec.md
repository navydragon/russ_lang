# Spec Delta

## Purpose

Показывать изменения заданий и сохранять общее подтверждение их проверки на странице запуска заданий.

## ADDED Requirements

### Requirement: Дата правок на карточке
Система SHALL показывать надпись «Внесены правки» и дату последней известной правки на карточке каждого изменённого задания.

#### Scenario: Изменённое задание
- **WHEN** для задания известна дата правки
- **THEN** карточка показывает «Внесены правки» и дату в формате ДД.ММ.ГГГГ

#### Scenario: Дата правки отсутствует
- **WHEN** дата правки задания неизвестна
- **THEN** система не выдумывает дату и не показывает отметку как подтверждённую правку

### Requirement: Общее подтверждение карточки
Система SHALL позволять любому посетителю страницы установить и снять подтверждение каждого задания и сохранять его в базе сервера независимо от результатов учеников.

#### Scenario: Подтверждение и обновление
- **WHEN** посетитель подтверждает задание и обновляет страницу или её открывает другой посетитель того же сервера
- **THEN** карточка отображает сохранённое подтверждение

#### Scenario: Снятие подтверждения
- **WHEN** посетитель снимает подтверждение
- **THEN** оно отсутствует после обновления и для других посетителей того же сервера

#### Scenario: Ошибка сохранения
- **WHEN** сервер не сохранил изменение
- **THEN** карточка сообщает об ошибке и не показывает несохранённое состояние как сохранённое

#### Scenario: Неизвестный код или режим без DEBUG
- **WHEN** отправлен неизвестный код задания или DEBUG выключен
- **THEN** изменение не сохраняется и страница и API подтверждения недоступны вне DEBUG
