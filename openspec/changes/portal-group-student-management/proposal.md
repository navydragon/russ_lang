# Proposal

## Why

Сейчас управление группами в russ_lang изменяет только локальные данные, а импорт студентов доступен лишь через консоль. Администратору нужен единый интерфейс, который создаёт и редактирует группы и студентов также на основном портале через api.emiit.ru, безопасно обрабатывая повторные запросы.

## What Changes

- Добавить создание и редактирование студентов через модалки на странице группы, скачивание Excel-шаблона, предварительную проверку и импорт в выбранную группу.
- Связать операции интерфейса с серверными запросами Django к отдельным операциям модуля russian_language API портала.
- Сопоставлять группы по уникальному code, студентов по уникальному code = login; сохранять возвращённые ID портала.
- Обеспечить идемпотентное создание и импорт: использовать существующие записи, обновлять ФИО и почту, сохранять пароль существующего пользователя, не дублировать членство.
- Снимать членство при удалении студента из группы в обеих системах, сохраняя пользователя и результаты. Удалять только пустые группы.
- Показывать ошибки и частичные результаты импорта; повторять незавершённые операции без дублей.

## Capabilities

### New Capabilities

- `group-student-management`: интерфейс управления группами, студентами и импортом в выбранную группу.
- `portal-roster-sync`: контракт и согласованность операций с пользователями, группами и членством основного портала.

### Modified Capabilities

Нет: основной каталог спецификаций пока пуст.

## Impact

- russ_lang: students/models.py, forms.py, views.py, urls.py, templates/students/, новый сервис интеграции и проверки импорта, миграции, настройки подключения и тесты.
- Отдельный репозиторий API: C:/Program Files/WebSoft/WebSoftServer/wt/web/api; маршруты index.html, libs/russian_language.js и необходимые collections. Этот change хранит общий контракт, но реализация API требует работы в его репозитории и соблюдения его инструкций.
- Используется существующий openpyxl; сетевой клиент выбирается из доступных зависимостей при реализации.
- Существующий консольный импорт сохраняет прежнее поведение; автоматическая массовая синхронизация старых данных не входит в change.
- Семестры, дисциплины, сценарий создания студента ДОТ, полное удаление пользователей и смена существующих паролей не входят в change.
