# Spec Delta

## Purpose

Обеспечивать согласованные и повторяемые операции russ_lang с группами, пользователями и членством основного портала через отдельный API русского языка, сохраняя существующие учётные записи и результаты.

## ADDED Requirements

### Requirement: Защищённый серверный обмен
Система SHALL выполнять запросы к API портала с сервера russ_lang по HTTPS с отдельной авторизацией интеграции; HTTP SHALL разрешаться только для loopback при локальной разработке. API SHALL проверять право интеграции на каждую операцию записи и не раскрывать секреты браузеру или журналам.

#### Scenario: Нет полномочий
- **WHEN** запрос записи не имеет действительной авторизации интеграции
- **THEN** API возвращает 401 или 403 без изменения данных

#### Scenario: Локальная разработка
- **WHEN** настроен адрес HTTP с hostname 127.0.0.1, localhost или ::1
- **THEN** адаптер допускает локальное соединение с той же проверкой авторизации, сохраняя запрет HTTP для внешних адресов

### Requirement: Общие уникальные ключи
API SHALL идентифицировать группу по уникальному code, а студента по code = login, возвращая ID портала строками. Неоднозначное сопоставление SHALL завершаться конфликтом без выбора произвольной записи.

#### Scenario: Существующий пользователь
- **WHEN** запрос содержит code и login существующего пользователя с одинаковым значением
- **THEN** API использует его ID и не создаёт нового пользователя

#### Scenario: Неоднозначная группа
- **WHEN** на портале обнаружено несколько групп с одним code
- **THEN** API возвращает 409 и не изменяет найденные группы

### Requirement: Повторяемые операции
API SHALL обеспечивать идемпотентное создание или обновление группы и студента, добавление и снятие членства и удаление пустой группы, включая повтор после потери ответа и одновременные запросы одного ключа.

#### Scenario: Ответ потерян
- **WHEN** портал выполнил создание, ответ потерян, а russ_lang повторяет запрос
- **THEN** API возвращает существующий объект без дублей пользователя, группы и членства

#### Scenario: Параллельные запросы
- **WHEN** одновременно поступают два запроса создания одного code
- **THEN** появляется не более одной записи, а запросы возвращают её либо повторяемый конфликт занятости

### Requirement: Обновление данных без смены пароля
API SHALL обновлять ФИО и почту найденного студента и сохранять пароль существующей учётной записи. Пароль из шаблона SHALL применяться только при создании нового пользователя и не сохраняться в локальном профиле студента.

#### Scenario: Пароль при повторном импорте
- **WHEN** существующий студент повторно импортируется с другим значением password
- **THEN** ФИО и почта обновляются, а пароль портала остаётся прежним

### Requirement: Изолированное управление членством
API SHALL изменять только указанное членство группы русского языка. Операции SHALL сохранять другие членства, результаты и пользователя, не назначая семестры, дисциплины или программу ДОТ.

#### Scenario: Добавление существующего пользователя
- **WHEN** существующий пользователь добавляется в группу русского языка
- **THEN** API добавляет только отсутствующее членство, сохраняя остальные связи

#### Scenario: Повторное снятие членства
- **WHEN** запрос снимает уже отсутствующее членство
- **THEN** API возвращает успешный результат без изменений пользователя и результатов

### Requirement: Согласованность результата
Система SHALL фиксировать подтверждённое локальное изменение после успешного ответа портала. При таймауте или ошибке локального сохранения система SHALL показывать незавершённый результат и допускать безопасный повтор без объявления ложного успеха.

#### Scenario: Сбой локального сохранения
- **WHEN** портал выполнил операцию, но локальная БД не сохранила результат
- **THEN** операция не объявляется завершённой, а повтор сопоставляет записи по общим ключам и завершает локальное сохранение

### Requirement: Защита удаления группы
API SHALL отклонять удаление непустой группы; повторное удаление уже отсутствующей группы SHALL считаться успешным. Запрос удаления SHALL затрагивать только группу, доступную интеграции русского языка.

#### Scenario: Удаление непустой группы
- **WHEN** в удаляемой группе на портале есть хотя бы один участник
- **THEN** API возвращает конфликт и сохраняет группу и её участников
