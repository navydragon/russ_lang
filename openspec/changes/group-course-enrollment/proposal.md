# Proposal

## Why

Группы и студенты уже синхронизируются с основным порталом, но создание пользователя не выдаёт ему учебные курсы. Администратору нужен выбор нескольких курсов для группы с автоматическим назначением новым и текущим студентам без дублей и потери результатов.

## What Changes

- Добавить курсу поле «ID WebSoft»; связать существующий основной курс «Русский язык для иностранных студентов» с `7221015156608859696`, сохранив его локальный ID, уроки, задания и результаты.
- Добавить группе выбор нескольких курсов при создании и редактировании.
- При создании, редактировании и импорте студента обеспечивать назначения всех текущих курсов его группы через защищённый API русского языка.
- При сохранении набора курсов группы доназначать выбранные курсы всем её текущим студентам; повтор операции восстанавливает незавершённые назначения.
- Сохранять ранее выданные назначения при удалении курса из списка группы и при исключении студента. Существующие и завершённые обучения и их результаты не сбрасывать.
- Показывать частичные ошибки назначения и разрешать безопасный повтор, не объявляя незавершённую синхронизацию успешной.

## Capabilities

### New Capabilities

- `group-course-enrollment`: связь локальных курсов с WebSoft, выбор курсов группы и выдача соответствующих назначений её студентам.

### Modified Capabilities

Нет: основной каталог openspec/specs пока пуст. Change расширяет реализованный portal-group-student-management, не дублируя его контракт управления пользователями и членством.

## Impact

- russ_lang: courses/models.py, courses/admin.py, миграции, courses/course_sync.py и тесты sync_russian_course; students/models.py, forms.py, roster.py, portal.py, шаблоны управления группой и проверки импорта.
- Отдельный репозиторий WebSoft API `C:/Program Files/WebSoft/WebSoftServer/wt/web/api`: index.html, libs/russian_roster.js, контрактные тесты и документация. Планирование хранится в russ_lang; изменения API реализуются в его репозитории.
- Используется штатная tools.activate_course_to_person, без назначения семестров и дисциплин. Механизмы авторизации, общих ключей и сохранения паролей остаются прежними.
- Не входят: снятие назначений, перезапуск завершённых курсов, синхронизация кураторов, изменение отчётов и автоматическая выдача курса всем историческим группам при миграции.
