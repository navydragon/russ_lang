# Spec Delta

## Purpose

Определять курсы обучения для группы russ_lang и обеспечивать соответствующие назначения её студентам в WebSoft при создании, импорте и изменении набора курсов, сохраняя ранее выданные назначения и результаты.

## ADDED Requirements

### Requirement: Связь курса с WebSoft
Система SHALL хранить для курса отдельное поле «ID WebSoft» с точным положительным числовым идентификатором и передавать его в API строкой без потери точности. Основной курс «Русский язык для иностранных студентов» SHALL получить ID `7221015156608859696` без пересоздания локального курса.

#### Scenario: Существующий основной курс
- **WHEN** применяется миграция или повторно выполняется его штатная синхронизация
- **THEN** курс получает указанный ID, сохраняет локальный ID, уроки, задания и результаты, а повтор не создаёт второй курс

#### Scenario: Непривязанный курс
- **WHEN** курс не имеет ID WebSoft
- **THEN** он остаётся в локальном каталоге, но попытка выбрать его для назначения группе отклоняется до сетевой записи с понятной ошибкой

### Requirement: Несколько курсов группы
Система SHALL позволять сотруднику с is_staff выбирать несколько курсов при создании и редактировании группы и показывать текущий выбор. Существующие группы SHALL сохраняться без автоматической выдачи курсов при миграции; пустой набор SHALL означать отсутствие новых назначений.

#### Scenario: Создание группы с несколькими курсами
- **WHEN** сотрудник сохраняет группу с двумя связанными с WebSoft курсами
- **THEN** оба курса становятся текущим набором группы и доступны для назначения её студентам

### Requirement: Назначение при сохранении студента
Система SHALL обеспечивать назначение всех текущих курсов группы при создании, редактировании и импорте студента после подтверждения пользователя и членства на портале. Повторный импорт существующего студента SHALL восстанавливать недостающие назначения.

#### Scenario: Импорт нового студента
- **WHEN** импортируется новый студент группы с двумя курсами
- **THEN** WebSoft содержит пользователя, членство и назначения обоих курсов, а успешная строка импорта подтверждает все эти действия

#### Scenario: Группа без курсов
- **WHEN** сохраняется студент группы с пустым набором курсов
- **THEN** пользователь и членство сохраняются по прежним правилам без запроса назначения курса

### Requirement: Доназначение текущим студентам
Система SHALL при сохранении набора курсов группы обеспечивать назначения выбранных курсов всем её текущим студентам в russ_lang. Повтор того же сохранения SHALL довыдавать недостающие назначения без изменения уже существующих.

#### Scenario: Добавление курса
- **WHEN** группе с существующими студентами добавляется курс
- **THEN** каждый её текущий студент получает недостающее назначение этого курса, а новый студент получает его при последующем создании или импорте

### Requirement: Сохранность назначений и результатов
Система SHALL сохранять существующие активные и завершённые обучения, их прогресс и результаты. Повтор назначения той же пары студент–курс SHALL не создавать дубль, не сбрасывать прогресс и не запускать завершённый курс повторно.

#### Scenario: Завершённый курс
- **WHEN** для студента с завершённым курсом повторяется импорт или сохранение списка курсов группы
- **THEN** завершённое обучение и его результаты сохраняются, а новое активное обучение по тому же курсу не создаётся

### Requirement: Удаление из текущего набора без отзыва
Система SHALL при удалении курса из списка группы сохранять все ранее выданные назначения. Исключение студента из группы SHALL также сохранять его обучения. Последующие студенты SHALL получать только текущий набор курсов.

#### Scenario: Курс убран из группы
- **WHEN** курс удаляется из текущего набора группы
- **THEN** ранее зачисленные студенты сохраняют его назначение, а будущий студент этой группы не получает убранный курс автоматически

### Requirement: Защищённое назначение
API SHALL разрешать назначение только учётной записи интеграции и только студентам, чьё членство в указанной группе русского языка подтверждено. Курс SHALL существовать в WebSoft; невалидный курс или чужая группа SHALL отклоняться без выдачи новых назначений.

#### Scenario: Неизвестный курс
- **WHEN** запрос содержит ID отсутствующего курса
- **THEN** API возвращает ошибку валидации до выдачи назначений по запросу

### Requirement: Частичные ошибки и восстановление
Система SHALL показывать ошибки назначения с указанием студента и курса, сохранять уже выполненные операции портала и допускать безопасный повтор. Сохранение группы или строки импорта SHALL не объявляться успешным, пока все запрошенные назначения не подтверждены.

#### Scenario: Сбой после части назначений
- **WHEN** один курс назначен, а следующий запрос завершается ошибкой или теряет ответ
- **THEN** интерфейс сообщает о незавершённой операции; повтор использует уже выданное назначение и завершает недостающие без дублей
