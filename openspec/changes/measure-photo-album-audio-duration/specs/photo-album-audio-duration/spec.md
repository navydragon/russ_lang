# Spec Delta

## Purpose

Обеспечить независимое измерение длительности записей чтения и устных текстов с учётом настроек каждого задания.

## ADDED Requirements

### Requirement: Сервер измеряет длительность записи
Система SHALL определять длительность загруженного аудиофайла для заданий чтения и устных текстов независимо от ответа распознавания, включая WebM/Opus из браузера.

#### Scenario: Запись укладывается в лимит
- **WHEN** измеренная длительность не превышает лимит конкретного задания
- **THEN** условие длительности выполнено и остальные критерии оцениваются по правилам задания

#### Scenario: Превышен лимит задания
- **WHEN** измеренная длительность превышает лимит конкретного задания
- **THEN** система применяет существующее условие времени этого задания и сообщает о превышении

#### Scenario: Лимит не установлен
- **WHEN** для задания отсутствует ограничение времени
- **THEN** система не вводит новый лимит и не отклоняет запись по длительности

#### Scenario: Длительность недоступна
- **WHEN** файл повреждён, формат не поддерживается или измеритель недоступен
- **THEN** система сообщает об ошибке проверки времени и предлагает повторить попытку без выставления итогового учебного результата

#### Scenario: Противоречие ответа распознавания
- **WHEN** сервис распознавания возвращает длительность, отличную от измеренной сервером
- **THEN** применяется длительность, измеренная по файлу
