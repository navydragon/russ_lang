# Proposal

## Why

Проверка чтения и устных текстов зависит от длительности в ответе распознавания, которая может отсутствовать. Необходимо проверять лимит каждого задания по самому аудиофайлу на сервере.

## What Changes

- Определять длительность загруженной записи на сервере независимо от распознавания.
- Сохранять индивидуальные ограничения заданий и отсутствие лимита там, где он не установлен и явно сообщать о невозможности измерить запись, не выдавая её за незачёт по чтению.
- Проверить поддерживаемый браузером WebM/Opus, пограничные значения и доступность инструмента в окружениях запуска.

## Capabilities

### New Capabilities

- `photo-album-audio-duration`: общий серверный контроль длительности для чтения и устных текстов с настройками каждого задания.

### Modified Capabilities

Нет основных спецификаций для изменения.

## Impact

`api/reading_check.py`, API и страница задания, тесты и документация развёртывания; возможно потребуется системная зависимость для анализа аудио. Затронуты задания чтения и устного пересказа; существующие лимиты и отсутствие лимита сохраняются.
