# Задания

## Локальная проверка

1. Заполните `LLM_API_KEY` и `NEXARA_API_KEY` в `.env`; установите `DEBUG=True` и `AUTO_START_EMAIL_FORWARDER=false`.
2. Выполните `python manage.py migrate`.
3. Выполните `python manage.py seed_ai_test_data`.
4. Запустите `python manage.py runserver 127.0.0.1:8888`.
5. Откройте `http://127.0.0.1:8888/dev/tasks/`.

Команда создаёт отдельный тестовый курс с четырьмя уроками и всеми 31 заданиеми из `AI_ASSIGNMENTS.md`, группу и ученика с кодом `AI_TEST_STUDENT`. Повторный запуск не удаляет попытки и не создаёт дубли. Если код задания занят записью другого курса, команда прерывается без изменения данных.

Страница запуска устанавливает cookie `student_code=AI_TEST_STUDENT` для текущего хоста. Двадцать два существующих задания открываются в новых вкладках; после отправки ответа вернитесь и нажмите «Обновить результаты», чтобы увидеть последние 20 попыток. Cookie не переносится между `localhost` и `127.0.0.1`: используйте один адрес `127.0.0.1:8888` для всего сценария. ИИ отвечает через реальные сервисы; подставляется только личность тестового ученика.

Тестовая страница и команда создания данных доступны только при `DEBUG=True`.

Адрес всех API-запросов определяется общим `api-config.js`: `https:` → `https://russ.emiit.ru`; остальные протоколы, включая `http:` и `file:`, → `http://127.0.0.1:8888`. Коды заданий имеют вид `AI_Nурока_Nзадания`; полное соответствие приведено в таблице `AI_ASSIGNMENTS.md`. При создании новых страниц используйте код из этой таблицы в `TASK_CODE`.

### Ударения в озвучке диктантов

Оба диктанта генерируются через Windows Irina и SSML `<phoneme alphabet="ipa">`.
В `audio/words.json` поле `noun` — исходный текст, `pronunciation` содержит текст каждого слова,
читаемое ударение (`stressed`) и фонетическую транскрипцию (`ipa`). Знак `ˈ` перед слогом в IPA
задаёт основное ударение. Заглавные буквы в исходном тексте для этого не используются.
Правильные ответы и оценивание от транскрипции не зависят.

Перегенерация из корня проекта (Windows PowerShell 5):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/generate_dictation_audio.ps1 -TaskDirectory dictation_1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/generate_dictation_audio.ps1 -TaskDirectory dictation_2
```

При отсутствующей транскрипции или ошибке синтеза существующие записи сохраняются.
После изменения произношения прослушайте новые записи; автоматическая проверка WAV подтверждает
целостность файлов, но не заменяет слуховую проверку диктором.

Озвучка диктантов по умолчанию замедлена: `-SpeechRate 0.85` (85% исходного темпа). Параметр генератора позволяет изменить скорость; `-SpeechRate 1.0` возвращает обычный темп.

В IPA обязательно обозначать **все** слоги точками, например `kə.rən.dʌ.ˈʂɨ` для «карандаши́». Без полного деления Microsoft может поставить ударение на предыдущий слог. Генератор проверяет это до синтеза.

Перед произношением в каждом аудиофайле диктантов добавлена пауза 500 мс (`<break time="500ms"/>` в генераторе).

Перед паузой 500 мс добавлен тихий сигнал 660 Гц длительностью 150 мс (около −30 dBFS, плавные края). Генератор автоматически добавляет его через `scripts/add_dictation_cue.py` в промежуточные WAV перед публикацией. Это позволяет проверить, уменьшится ли обрезание начала слова в беспроводных наушниках.

### Пробная озвучка Yandex SpeechKit

Ключ и параметры задаются в `.env`: `YANDEX_SPEECHKIT_API_KEY`, `YANDEX_SPEECHKIT_VOICE`,
`YANDEX_SPEECHKIT_ROLE`, `YANDEX_SPEECHKIT_SPEED` (пример в `.env.example`).
Для синтеза одного предложения используется платный API v3, без автоматических повторов запросов.

```powershell
python scripts/generate_yandex_dictation_audio.py --sentence 5
```

Скрипт сохраняет образец в `lesson3/novgorod_dictation/samples/yandex_05.wav`,
не заменяя рабочую озвучку. Можно выбрать предложение 1–10. Сохраняются исходная пунктуация,
ударения (`+` перед ударной гласной в TTS-разметке), тихий сигнал 150 мс и пауза 500 мс.
Ключ остаётся на компьютере и не передаётся в браузер. Сгенерированный образец № 5:
Marina / friendly / 0.7. Проверен успешный ответ сервиса и структура WAV; слуховая оценка требуется.


### Текущая озвучка всех диктантов — Yandex SpeechKit

Рабочие записи `AI_3_7`–`AI_3_10` (25 + 17 + 21 + 10 = 73 WAV) заменены на
SpeechKit: **Marina / friendly / 0.7**, с ударениями в TTS-разметке, тихим сигналом 150 мс
и паузой 500 мс. Описанный выше Windows/IPA-генератор сохранён как альтернативный;
текущие WAV созданы Yandex, а не Irina. Начальные тишина и сигнал добавляются локально:
SpeechKit не гарантирует паузу в начале текста.

```powershell
python scripts/generate_yandex_dictation_audio.py --all --publish
```

Без `--publish` файлы только подготавливаются. Кеш по тексту, голосу, амплуа и скорости
сохраняется в `.speechkit-cache/generated/`; повторный запуск не запрашивает готовые записи.
При сетевой ошибке можно повторить ту же команду. Автоматических сетевых повторов нет.
Рабочие файлы заменяются только после генерации и проверки всего пакета. Старые записи
сохраняются в `.speechkit-cache/backups/`. Этот каталог исключён из Git.
Изменение текста или настроек приводит к новым платным запросам; ключ не попадает в WAV или браузер.


В `AI_3_8` озвучиваются пары **в единственном числе**, а ответ вводится во множественном:
«лампа и карандаш» → «лампы и карандаши», «учебник и день» → «учебники и дни».
17 исходных пар и их ударения записаны в `lesson3/dictation_2/audio/words.json`.
Оценивание сохранено: 5 пар, по 10 баллов за каждое существительное, зачёт от 60.
Перегенерация только этого задания:

```powershell
python scripts/generate_yandex_dictation_audio.py --task dictation_2 --publish
```

Параметр `--task` также принимает `dictation_1`, `dictation_3`, `novgorod_dictation`.
