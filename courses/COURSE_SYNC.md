# Создание курса русского языка

Команда `sync_russian_course` добавляет курс «Русский язык для иностранных студентов», уроки с позициями 1–10, 105 обычных заданий из `courses/Книга русский.xlsx` и 31 ИИ-задание из `courses/task_catalog.py`.

## Выполненный запуск

25 октября 2026 года команда применена к продовой PostgreSQL через SSH-туннель. Переиспользованы курс с ID 1 и 10 существующих уроков. Добавлено 137 заданий: 105 обычных и 32 ИИ-задания. Шесть ранее существовавших заданий сохранены; всего в курсе 143 задания. Повторная проверка показала 0 добавлений и 0 обновлений кодов. Все 32 ИИ-кода проверены на принадлежность нужному уроку.

В исходном Excel обычные задания есть только для уроков 1–4. ИИ-задания также определены только для уроков 1–4. Уроки 5–10 создаются без придуманных заданий.

Существующие курсы, задания, позиции, названия и попытки не удаляются. Уроки сопоставляются по позиции внутри курса, а не по старым первичным ключам из Excel. Новые задания добавляются после существующих. При наличии старого кода ИИ-задания в целевом курсе обновляется только код, сохраняя ID и связанные результаты. Неоднозначные дубли и коды, занятые другим курсом, приводят к отмене операции.

## Подключение к PostgreSQL

В `.env` нужны `DB_ENGINE=postgres`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`. Опциональны `DB_CONNECT_TIMEOUT` и `DB_SSLMODE`.

Профиль `config.course_sync_settings` использует эти параметры только при явном выборе. Обычный локальный сервер и тесты продолжают использовать SQLite. В профиле синхронизации `DEBUG=False`, поэтому тестовая страница и команда создания тестового ученика недоступны.

Проверка плана без записи:

```powershell
python manage.py sync_russian_course --settings=config.course_sync_settings
```

Применение одной транзакцией:

```powershell
python manage.py sync_russian_course --settings=config.course_sync_settings --apply
```

Повторная проверка должна показать ноль новых курсов, уроков, заданий и ноль обновлений кодов. Если в БД есть дополнительные задания, они сохраняются. Команда не запускает миграции и не создаёт тестовых учеников.

## Подключение через SSH

Если PostgreSQL доступен только на сервере, откройте туннель в отдельном терминале:

```powershell
ssh -N -L 127.0.0.1:15432:127.0.0.1:5432 -o ExitOnForwardFailure=yes root@185.219.43.204
```

В терминале для команды задайте только адрес туннеля; имя БД, пользователь и пароль останутся взяты из `.env`:

```powershell
$env:COURSE_SYNC_DB_HOST='127.0.0.1'
$env:COURSE_SYNC_DB_PORT='15432'
python manage.py sync_russian_course --settings=config.course_sync_settings
python manage.py sync_russian_course --settings=config.course_sync_settings --apply
python manage.py sync_russian_course --settings=config.course_sync_settings
```

## Коды ИИ-заданий

Формат — `AI_Nурока_Nзадания`, где второй номер — порядок ИИ-задания внутри урока, не общая позиция среди обычных заданий и не номер слайда. Существующие коды не перенумеровываются при добавлении следующих заданий.

- Урок 1: `AI_1_1`–`AI_1_5`.
- Урок 2: `AI_2_1`–`AI_2_2`.
- Урок 3: `AI_3_1`, `AI_3_2`, `AI_3_4`–`AI_3_11`. Код `AI_3_3` исключён как дубль и не используется повторно.
- Урок 4: `AI_4_1`–`AI_4_14`.

Точные названия и коды всех 31 задания приведены в [AI_ASSIGNMENTS.md](../tasks/AI_ASSIGNMENTS.md). В новых HTML-страницах задавайте соответствующий `TASK_CODE`; внутренний `TASK_ID` проверяющего API остаётся отдельным идентификатором (`family`, `room`, `university` и т. п.). Коды шести существующих страниц уже приведены к этому формату.

Изолированная проверка команды и страницы запуска:

```powershell
python manage.py test courses.tests.test_course_sync courses.tests.test_ai_test_launcher --noinput
```

## Исключённый дубль

`AI_3_3` дублировал пересказ `AI_3_2` и исключён из каталога. Остальные коды сохранены; сквозная нумерация перечня теперь 1–31. Команда `remove_duplicate_ai_task` проверяет отсутствие попыток и завершений; с `--apply` удаляет только пустую заглушку в основном или тестовом курсе. При наличии результатов удаление отменяется. Синхронизация курса больше не создаёт этот код.
